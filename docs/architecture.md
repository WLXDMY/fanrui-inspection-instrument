# 架构说明

```text
凡瑞 QMS 检验仪器前端
  ├─ /factory/v1/                     原仪器列表、分类、详情和基础保存
  └─ /instrument-extension/api/v1/   扩展字段定义、绑定和字段值
          │
          ▼
     Nginx 同源路由
          │
          ▼
     独立 Spring Boot 服务
          │
          ▼
     独立 MySQL / Flyway
```

## 绑定原则

仪器编号和名称均可能被修改，因此不能作为唯一技术主键。扩展服务使用原系统提供的稳定仪器 ID 建立绑定，编号、名称和状态只保存为可更新的业务快照。

## 保存顺序

1. 保存原仪器基础信息。
2. 原保存成功后同步仪器绑定快照。
3. 保存该仪器的扩展字段值。
4. 重新调用聚合接口读回字段和值。

写请求不自动进行网络重试，避免在慢网环境中产生重复操作。只读 GET 请求可以在刷新宿主运行参数后重试一次。

## 多网络访问

浏览器端不直接访问写死的设备私网 IP。前端读取宿主当前 `baseUrl`，通过同源路径访问扩展服务；每个实际宿主入口都必须配置相同的 Nginx location。
